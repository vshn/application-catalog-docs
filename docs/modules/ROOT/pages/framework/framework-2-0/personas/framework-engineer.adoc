= Framework Engineer
:navtitle: Framework Engineer

Framework Engineers maintain the platform infrastructure, composition functions, KCL framework, CI/CD, and testing infrastructure.

== Requirements

As a Framework Engineer I:

* Maintain the framework's core infrastructure and tooling
** Own the documentation and runbooks for the framework
* Supports service maintainers and operators in their work by creating guides, runbooks, and troubleshooting documentation
* Provides 3rd level platform support for service maintainers and operators
* Resolves conflicts between shared resources and services
** Has the final say on allowed service permissions and resource usage
* Manage platform components and integrations
** S3, backup infrastructure, monitoring, logging, etc.
** Load balancing, ingress, and TLS termination
